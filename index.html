Drug Interaction Checker

Query the FDA's public label database in real time. Enter two medications, get back the actual interaction language from official labeling, graded by severity. Sign in to unlock the live checker.

01 · Data

      
Live queries against openFDA's official drug label endpoint — no local dataset, always current.

    

    

      
02 · Logic

      
Rule-based NLP scans each label for mentions of the paired drug and grades severity by keyword signal.

    

    

      
03 · Stack

      
Vanilla JS, zero dependencies, fully client-side — runs entirely in your browser.
